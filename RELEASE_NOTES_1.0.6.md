# Nomadic v1.0.6 Release Notes

## 🚀 What's New in v1.0.6

### 🎯 Zero-Failure Full-Spectrum Form Solver
- **Top-to-Bottom Systematic Page Scrolling:** Automatically scans and mounts all virtualized React 18+ components and sub-sections before form execution.
- **Dedicated Ashby System Identifiers:** Direct native targeting for `#_systemfield_name`, `#_systemfield_email`, `#_systemfield_phone`, `#_systemfield_location`, `#_systemfield_resume`.
- **Complete Option Question & Yes/No Button Solving:** Correctly solves Ashby `_yesno_` buttons, ARIA radiogroups, and custom dropdown comboboxes (`Work Auth` → Yes, `Visa Sponsorship` → No, `Office 3 Days` → Yes).
- **Comprehensive Legal Agreements & Certifications:** Checks all arbitration agreements, applicant certifications, and terms checkboxes with synthetic click bubbling.
- **Automatic Submission & Confirmation:** Automatically locates primary submit buttons, applies human timing jitter, clicks submit, and confirms application completion.

*Update mandatory. Installs seamlessly over v1.0.0 — v1.0.5 using the integrated updater pipeline.*
